# Contributing to Chrome Tamer

We welcome contributions from the "Real Tech" community.

## Philosophy

*   **Logic over Heuristics**: Prefer calculated utility (Game Theory) over arbitrary timers.
*   **Performance First**: The extension itself must use <10MB of RAM.
*   **Privacy Absolute**: No analytics injection into user pages.

## Development Setup

1.  `npm install`
2.  Load `extension/` directory as an unpacked extension in Chrome.
3.  Debug logic in `background.js` console.

## Pull Request Process

1.  Fork the repo.
2.  Create your feature branch (`git checkout -b feature/NashOptimization`).
3.  Commit your changes.
4.  Open a PR describing the mathematical impact of your change.
