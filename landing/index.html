Technical FAQ

Is this just a tab suspender? ▼
No. Unlike basic suspenders that use fixed timers, Chrome Tamer identifies "dominated strategies" in your resource pool. It considers system pressure, domain redundancy, and recency to act with precision.
How does the Native Kernel help? ▼
Chrome extensions are limited to high-level browser APIs. Our Native Kernel uses `taskpolicy` (macOS) and `EmptyWorkingSet` (Windows) to reclaim memory at the OS level that Chrome refuses to release.
